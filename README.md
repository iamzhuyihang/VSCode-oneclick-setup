# VS Code 一键安装配置工具 (Windows)

一款专为 Windows 打造的全自动、极速、无忧的 VS Code 环境部署工具。只需双击运行，即可全自动完成 VS Code 的安装、汉化以及常用编程语言插件的配置，真正做到“一键解放双手”。

---

## ✨ 核心功能

*   **🔍 智能检测，拒绝重复安装**
    *   采用注册表级检索技术，无论你以前把 VS Code 装在了 C 盘还是 D 盘，工具都能 0.1 秒瞬间定位。已安装则直接跳过，不占用多余磁盘寿命。
*   **⚡ 极速下载，防断网防损坏**
    *   优先使用 `curl` 引擎多线程极速下载，并带有文件头 (PK) 校验。网速再差也能自动回退到 `PowerShell` 下载，彻底杜绝“下载后安装失败”的红字报错。
*   **🧩 插件一键多选**
    *   内置 C/C++、Python、Java、Go、Ruby、PHP 等主流语言插件，支持输入编号一键多选安装。
*   **🛡️ 纯净安装，“阅后即焚”**
    *   支持自定义安装目录，静默配置环境变量 (PATH) 和右键菜单。执行完毕后，自动清理所有下载的安装包、插件包和临时文件，只留日志，不留垃圾。
*   **🌐 强制汉化**
    *   自动在线获取并安装官方最新简体中文语言包，自动修改配置，将界面语言锁定为中文。

## 🚀 如何使用

**第一步：准备环境**
*   请确保电脑处于联网状态。
*   关闭正在运行的 VS Code（如果已经打开的话）。

**第二步：运行工具**
*   找到 `VSCode一键安装配置.exe` 文件。
*   **【重要】** 鼠标右键点击该文件，选择 **“以管理员身份运行”**。
    *(如果不以管理员身份运行，会直接提示失败并退出)*

**第三步：按提示操作**
1.  **安装路径**：直接按回车（默认安装在 C 盘用户目录），或输入自定义路径（如 `D:\VSCode`）。
2.  **插件选择**：根据你的需要输入数字编号（例如输入 `1 2` 代表安装 C/C++ 和 Python，输入 `0` 跳过）。
3.  **桌面快捷方式**：输入 `Y` 创建桌面图标，输入 `N` 或直接回车跳过。
4.  全部完成后，按任意键即可关闭窗口。

## ❓ 常见问题 (FAQ)

**Q1：双击运行后，杀毒软件报毒或拦截怎么办？**
> 这是正常的。因为工具内部包含了下载网络请求、修改系统环境变量和注册表等敏感操作，极易被 Windows Defender、360、火绒等安全软件误判。**请在弹出的提示中选择“更多信息” -> “仍要运行”，或将其添加至信任区。**

**Q2：运行后提示“未以管理员身份运行”？**
> 请关闭窗口，右键点击 EXE 文件，选择“以管理员身份运行”重新执行。

**Q3：安装过程中报错说“下载失败”或“文件不完整”？**
> 这通常是因为网络波动导致。工具内置了重试和防损坏机制，它可能会自动重试或者回退用备用方式下载。如果最终依然提示失败，请检查你的网络环境（或代理软件），重新运行工具即可。

**Q4：运行完之后，文件夹里多了一个 `.log` 文件？**
> 这是安装日志文件（`VSCode_Install.log`），记录了每一步是否成功。如果你遇到问题，可以打开它看看是哪一步卡住了。如果不需要，可以直接删除。

**Q5：这个工具可以在一台完全没有网络的电脑上运行吗？**
> 如果处于离线状态，VS Code 和插件的下载会失败。但如果你提前准备了离线安装包（`.exe`）和插件包（`.vsix`），放入 EXE 同目录下的 `payloads` 文件夹中，工具依然可以帮你完成离线安装。
