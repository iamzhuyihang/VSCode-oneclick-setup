======================================================================
           VS Code 一键安装配置脚本 (Windows) - 功能简介
======================================================================
【核心优势】
彻底告别繁琐的“下载、下一步、改环境变量、找插件、装汉化”流程。
一个脚本，只需管理员双击，几分钟内为你打造一个开箱即用的 VS Code 环境。

【详细功能清单】
[0] 安全与权限
    - 强制管理员权限运行检查，避免安装失败。
    - 全程路径合法性校验（盘符检测、非法字符拦截、系统保护目录防呆）。

[1] 智能环境检测 (零磁盘磨损)
    - 独家的“注册表级”检索技术。不管你的 VS Code 是装在 C 盘、D 盘还是绿色路径，0.01秒精准定位，拒绝全盘扫描带来的硬盘寿命损耗。
    - 若检测到已安装，自动跳过安装环节，直接进入插件配置。

[2] 极速静默安装
    - 提供官方原版下载通道，支持 curl 极速下载，自带断点续传与 PowerShell 兜底。
    - 完美支持静默安装到自定义路径，静默配置环境变量 (PATH) 和右键菜单，不打扰你的工作。

[3] 必装中文语言包
    - 智能检索本地离线包；若未找到，自动在线连接微软市场，获取并安装最新版“简体中文语言包”。

[4] 丰富的语言插件矩阵
    - 支持一键多选安装：C/C++、Python、Java、Go、Ruby、PHP。
    - 独家“双重防损坏校验”：下载完成后自动检测文件大小与 PK 文件头。只要不是标准 ZIP 格式（如下载到了网页报错或截断包），自动判定失败并重试，彻底告别“扩展安装失败”红字。
    - C/C++ 模块内置极速下载引擎，速度提升十倍以上。

[5] 完美收尾与“阅后即焚”
    - 自动修改 argv.json，将界面语言锁定为 zh-cn（简体中文）。
    - 询问是否添加桌面快捷方式，并附带隐藏的极客小彩蛋（蓝色链接变蓝提示）。
    - 【核心清理功能】：执行完毕后，自动清理所有下载产生的 .exe 安装包、.vsix 插件包和临时文件夹。只留一个日志文件，让电脑硬盘干干净净！
